# 👁️ Proyecto de Visión Artificial con OpenCV y MediaPipe

## 📋 Descripción General
Este proyecto consiste en el desarrollo de una solución de automatización mediante **Visión Artificial**, integrando **OpenCV** y **MediaPipe** para resolver una problemática real de la industria en la región.

---

## 🎯 Objetivos y Alcance
- **🏭 Enfoque Industrial:** Seleccionar una industria real perteneciente a la región.
- **🔍 Identificación del Problema:** Investigar un proceso o tarea que represente un alto grado de repetitividad o riesgo operativo.
- **⚙️ Solución Funcional:** Diseñar e implementar un prototipo funcional capaz de automatizar o asistir en dicho proceso.

---

## 🛠️ Requerimientos Técnicos

Para cumplir con los criterios de diseño, la arquitectura del sistema debe integrar obligatoriamente los siguientes módulos:

### 1. OpenCV *(Seleccionar al menos **2** características)*
- [ ] **Detección de color** *(Color Detection)*
- [ ] **Filtros** *(Image Filtering / Smoothing)*
- [ ] **Segmentación** *(Image Segmentation)*
- [ ] **Contornos** *(Contour Detection)*
- [ ] **ROI** *(Region of Interest)*
- [ ] **Background Subtraction** *(Sustracción de fondo)*

### 2. MediaPipe *(Seleccionar al menos **1** característica)*
- [ ] **Face Detection** *(Detección de rostros)*
- [ ] **Face Mesh** *(Malla facial 3D)*
- [ ] **Hands** *(Seguimiento de manos y gestos)*
- [ ] **Pose** *(Estimación de postura corporal)*
- [ ] **Holistic** *(Seguimiento integral: rostro, manos y postura)*
